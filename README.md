# 📚 Library Management System

A full-stack Library Management System built using the MERN Stack.

This project allows administrators and users to manage books, memberships, reports, and book transactions with dynamic MongoDB integration.

---

# 🚀 Tech Stack

## Frontend

* React.js
* Vite
* Tailwind CSS
* React Router DOM
* Axios

## Backend

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose

---

# 📖 Book Management

* Add Books

# 🔄 Transactions

## Issue Book

* Issue Date Validation
* Return Date Validation
* Book Status Automatically Changes to Issued

## Return Book

* Checks if Book is Issued
* Updates Availability Automatically
* Redirects to Fine Payment Page

# ⚙️ Installation

## Clone Repository

```bash
git clone <your-github-repo-link>
```

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

## Backend Setup

```bash
cd server
npm install
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file inside the server folder.

```env
MONGO_URI=your_mongodb_connection_string
```
